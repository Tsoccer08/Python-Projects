# Python Projects

A collection of Python projects developed throughout my programming coursework. These projects demonstrate my experience with problem solving, algorithms, file processing, testing, and user interaction.

## Projects

### Adventure Game

A text-based adventure game where the player explores a hidden-choice story and makes decisions that affect the outcome.

**Concepts demonstrated:**
- Functions
- Conditional statements
- Loops
- User input
- Decision-making
- Program flow

---

### Shopping Cart

A console-based shopping cart program that allows users to add, view, remove, replace, and purchase items.

**Features:**
- Add items and prices
- View cart contents
- Remove items
- Replace items
- Calculate the cart total
- Complete a purchase

**Concepts demonstrated:**
- Lists
- Loops
- Conditional statements
- User input
- Basic data management

---

### Dungeon Game

A grid-based dungeon game where the player explores randomly generated rooms, collects potions, fights monsters, and eventually faces a boss.

**Features:**
- Randomly generated rooms
- Player movement
- Monsters and boss encounters
- Combat system
- Potion inventory
- Random potion drops
- Win and lose conditions

The project also includes a separate test file using `pytest` to test important game functions.

**Concepts demonstrated:**
- Functions
- Dictionaries
- Lists
- Randomization
- Game logic
- Automated testing
- Unit testing

---

### Power Analysis

A program that reads power measurement data from JSON files and calculates the highest average power using a sliding-window algorithm.

**Features:**
- Reads data from JSON files
- Validates input data
- Handles invalid files and values
- Calculates averages using a sliding window
- Includes sample datasets for testing

**Concepts demonstrated:**
- JSON file processing
- File input
- Error handling
- Assertions
- Lists
- Sliding-window algorithms

---

### Segregation Sort

An implementation of the segregation sort algorithm using a middle element as the pivot. The program partitions the array around the pivot and recursively sorts the resulting sections.

The project includes multiple test cases covering different types of input, including empty lists, duplicate values, negative integers, already sorted data, and general cases.

**Concepts demonstrated:**
- Sorting algorithms
- Recursion
- Array partitioning
- Functions
- Testing
- Algorithmic problem solving
